# Phase 1: Feel It Out

Get the core loop feeling right before expanding content.

## Goals

1. Smooth Xbox controller movement with analog stick
2. Fixed arena with camera follow
3. Enemies spawn and walk toward player
4. One auto-firing ranged weapon with projectiles
5. Wave timer (20s first wave, scaling to 60s)
6. Material drops + XP collection
7. Basic shop between waves

## Status

Starting implementation.
